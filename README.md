# Visual Data and Story Telling

**M.S. Data Analytics & Visualization — Yeshiva University, Katz School of Science and Health**

## Course Description

This course explores the art and science of communicating data insights through effective visualization and narrative techniques. Topics include visual perception principles, chart selection, dashboard design, interactive visualizations, and crafting compelling data stories for diverse audiences.

## Repository Structure

- `visualizations/` — Static and interactive visualization projects
- `notebooks/` — Jupyter notebooks with exploratory visual analysis
- `dashboards/` — Dashboard projects and prototypes
- `assignments/` — Coursework and visual design exercises
- `data/` — Datasets used in visualization projects

## Tools & Technologies

- Python (Matplotlib, Seaborn, Plotly, Altair)
- Tableau / Power BI
- D3.js
- Jupyter Notebooks
